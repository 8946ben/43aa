# 一个魂零食大作战
### 副题：深夜零食大作战 · 嘉然今天吃什么？

A-SOUL 同人深夜干饭钩爪小游戏。默认三人组**贝拉 / 嘉然 / 乃琳**均可作为可玩角色，
各自带真实生效的专属被动；深夜的地窖里堆满了零食，放下钩爪凑齐「今日菜单」订单、
达成解馋值目标——但要小心炸弹汽水罐和偷吃的阿草！（心宜、思诺在通关庆典横幅中客串。）

> **纯静态网页游戏**：零依赖、零构建、零联网，**双击 `index.html` 即可游玩**（file:// 协议直接可玩）。

---

## 灵感来源与原创设计

- **玩法基底**：借鉴 4399 经典《黄金矿工》的钟摆钩爪——钩爪左右摆动，
  点击放钩，钩中物品拉回，**越重拉得越慢**。
- **原创① 订单制**：每关开始先展示「今日菜单」订单，限时内
  凑齐订单物品并达到解馋值目标才算过关；一周 7 关（周一~周日），
  订单逐关复杂，周日是「火锅大宴」终极订单。
- **原创② 阿草偷吃**：吉祥物阿草（雪貂）在场地中横向游走，会冲向零食
  直接吃掉；被钩住会拖走 5 秒并偷吃背包里最后一件食物。
  抓到阿草不扣解馋值，但有彩蛋台词。
- **原创③ 连击**：连续抓中订单内的食物，连击倍率提升（每级 +0.2）；
  抓非订单食物只有小分，抓西兰花/石头会中断连击。
- **原创④ 三人可玩 + 专属被动**：贝拉 / 嘉然 / 乃琳机制各异（见下表）。

## 角色与专属被动（真实机制，非换皮）

| 角色 | 称号 | 被动 | 实现位置 |
| --- | --- | --- | --- |
| 贝拉 Bella（#DB7D74） | 队长 · 加练 | 每关时长 **+10 秒**；钩爪摆动速度 **+15%** | `newGame` 时间加成；`updateHook` 摆速乘 `swingMult` |
| 嘉然 Diana（#E799B0，默认主角） | 吃货 | 订单内食物得分 **+20%**；连击倍率上限 **×4.0**（其余 ×3.0） | `collect` 得分乘 `orderBonus`；倍率上限取 `comboCap` |
| 乃琳 Eileen（#576690） | Queen · 控场 | 阿草偷吃概率 **减半**（触发间隔 ×2、单关偷吃次数 2→1、挣脱偷吃 50% 失败）；被钩住的阿草**定身时间翻倍**（离场 4→8 秒）；汽水罐爆炸时间惩罚**减半**（-5s → -2.5s） | `spawnAcao`/`updateAcao` 偷吃频率；`acaoSteal` 概率与 `acaoStunMult`；`explode` 乘 `bombMult` |

- 三人拥有各自的表情包立绘、应援色与专属台词库（贝拉：每人加练一天！/ 努力闪耀 / 不会吧…；

- 最高分**按角色分别记录**：`localStorage` 键 `snackclaw_best_v2`
  （结构 `{bella:{score,day}, diana:{...}, eileen:{...}}`，旧版 `snackclaw_best_v1` 的嘉然纪录会自动迁移）；
  关卡解锁进度三人共享（`snackclaw_progress_v1`）。选人卡上显示各自最高纪录。

## 玩法说明

1. 标题界面点击**角色选择卡**挑选干饭人，再点「开始游戏」或任意已解锁关卡。
2. 点击鼠标 / 空格 / J 放钩，钩爪沿当前摆动方向伸出。
3. 钩中零食自动拉回，重量越大速度越慢；拉回顶端自动收入背包。
4. 凑齐订单 + 解馋值达标 → 立即过关（剩余时间折算奖励分）。
5. 物品按深度分层（浅层 / 中层 / 深层），**越深越值钱**，也越重。
6. 时间归零未完成订单 → 失去 1 次机会，3 次机会用完本关失败。

## 技术说明

- 内部分辨率 960x640，CSS 等比缩放自适应窗口；`requestAnimationFrame` + dt 驱动，60fps。
- 经典 `<script>` 顺序引入（data.js 先、game.js 后），无 ES module / fetch / Worker / 外部 CDN。
- 音效：WebAudio 振荡器合成（放钩 / 抓中 / 连击 / 爆炸白噪声 / 过关琶音 / 失败降调 /
  阿草滑音），外加 16 步轻量 BGM 循环（随关卡升调），静音状态本地记忆。
- 台词气泡：按所选角色弹出专属语音梗，事件触发专属台词（连击、磕到石头、爆炸、
  阿草偷吃、订单完成等），未覆盖的事件自动回退到通用台词库。
