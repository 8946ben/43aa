主循环与回合推进

main.js 用「固定步长累加器 + 渲染解耦」的经典模式驱动游戏；回合以 game.state 四态状态机推进，tickSettle 判定停稳后换下一个角色。

角色出场轮换

currentSkin() 按「已消耗弹数」对 Entities.BIRD_SKINS 取模轮换：贝拉 → 嘉然 → 乃琳 → 循环。分身（嘉然技能）不占回合数。

停稳判定的三个出口

飞行结束任一满足：速度 < 0.9 连续 26 帧；发射超 6500ms；飞出边界（x<-160 / x>W+200 / y>H+400）。之后固定等 650ms 再换弹，给坍塌留时间。

计分规则

消灭牛 +5000 / 拆方块 +500 / 过关剩余弹数每发 +10000。分数只增不减，HUD 实时同步 syncHud()。
