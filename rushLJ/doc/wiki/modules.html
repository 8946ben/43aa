模块与加载

五个 JS 文件全部是无打包的普通 <script>，加载顺序即依赖顺序；除 Matter 外每个文件只暴露一个全局对象（LEVELS / Entities / Slingshot / Render），main.js 是唯一组装者。

模块契约一览

全局暴露 API被谁调用
LEVELS纯数组，无方法main.js（选关菜单 / startLevel / HUD）
EntitiescreateBlock / createPig / createEgg / createBird / damage / decayFlash + 常量main.js、slingshot.js（轨迹预测）、render.js（图鉴）、main.js 图鉴
Slingshotinit / computeTrajectory / resetPouchmain.js
Renderdraw / drawBird / drawPig / drawSpriteCentered / readymain.js（帧循环 + 图鉴）

瞄准不进物理世界

Slingshot 拖拽时只改 game.previewBird（普通对象）与 game.pull，松手超过 14px 才回调 launch(velocity) 创建真刚体。这是为了避免 Matter 静态体反复增删造成的抖动。

输入绑定的两个来源

同一画布 pointerdown 有两个监听：Slingshot 内部处理瞄准拖拽（state 为 aiming 时生效），main.js 的 tryUseSkill 处理技能释放（state 为 flying 时生效）——靠 game.state 天然互斥。
