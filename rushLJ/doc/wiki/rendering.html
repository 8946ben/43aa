渲染管线

Render 完全接管画面：不使用 Matter 自带渲染器，每帧在 1280×720 逻辑坐标上重绘全部内容，DPR 缩放由 main.js 的 resizeCanvas 统一处理。角色外观优先用 assets/ 精灵贴图，矢量手绘只是加载失败的回退。

逻辑坐标固定 1280×720

CSS 把画布缩放到 min(100vw, 177.78vh) 保持 16:9；物理与关卡数据永远使用逻辑坐标，DPR 只影响画布分辨率，两者互不干扰。

矢量回退仍在维护

drawBella / drawJiaran / drawNailin / drawPigVector 是完整的矢量手绘实现，贴图加载失败时自动接管；图鉴头像先矢量绘制、贴图就绪后经 Render.ready 重绘为素材图。

drawBird / drawPig 是双用途 API

既服务游戏内实体，也被 main.js 的 drawGalleryPortraits 用作图鉴头像渲染入口 —— 所以 Render 模块必须保持「只依赖传入参数、不依赖 game 状态」的纯度。
