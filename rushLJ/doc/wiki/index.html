架构总览

Rush LJ 是一个纯静态弹弓物理小游戏：无构建工具、无 dev server，浏览器直接打开 index.html 即玩。物理由 Matter.js 驱动，画面全部走 Canvas 2D 自绘。下图即全站目录 —— 图中每个模块节点都可以点击跳转到对应详情页。

一句话架构

main.js 是唯一的状态拥有者：它创建 Matter 引擎与 game 对象，其余四个模块（level / entities / slingshot / render）都是无状态的服务方，围绕 game 与引擎单向协作，互相之间几乎不通信。

关键决策

瞄准阶段不进物理世界 —— 皮兜里的角色只是渲染预览，发射瞬间才调用 Entities.createBird 创建刚体，完全避开 Matter 静态体反复切换的抖动问题（见 模块与加载）。

玩法属性挂在刚体上

gameType / hp / skin / dead / hitFlash 等玩法字段直接写在 Matter body 上，渲染与主循环按字段判定，不维护 ID 映射表（见 实体与参数）。

运行环境注意

Matter.js 走 jsDelivr CDN，游戏本体需要联网；本 wiki 的 mermaid 已本地化到 assets/mermaid.min.js，双击即可离线阅读。
