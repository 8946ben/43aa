# 应援牌局 v0.2 打磨工单

在现有 v0.1 工程上增量实现（`index.html` + `style.css` + `js/*.js`，模块化，勿重写）。

## 1. 出牌动画与音效（打击感）
- 出牌：卡片从手牌位置飞向弃牌堆（CSS transform 过渡，约 220ms 缓动）
- 摸牌：牌背从摸牌堆滑入对应玩家手牌区
- 命中特效：+2/+4 打出时目标座位闪红晕；跳过牌打出时目标座位灰一下
- WebAudio 合成音效（零音频文件）：出牌(短促 click)、摸牌(纸摩擦噪声)、+2/+4(下滑低音)、胜利(上行琶音)、失败(下行)、应援成功(清脆铃音)
- 右上角静音按钮，偏好存 localStorage

## 2. 多轮积分赛制
- 改单局为「锦标赛模式」：3 局两胜（可配置 3/5 局），每局结束显示本局得分
- 累计积分榜：4 人座位按累计分排序展示
- 总局冠军结算页：显示完整排名 + 总积分 + 胜局数
- 保留「快速单局」入口（选择模式：单局 / 锦标赛）

## 3. 「+2/+4 叠加」规则选项
- 开局前设置面板增加开关「叠加模式」（默认关）
- 开启后：被 +2 时若手里有 +2 可反打，把罚牌累计转给下家（+4 同理，+4 压 +2 也允许）
- 累计到无人可接时，最后被指者摸全部累计张数
- UI 上显示当前累计罚牌数（如「罚牌 x4」）

## 4. 成员语录 toast
- 用成员设定语录（可硬编码 5 条，参考 A-SOUL 风格：贝拉"努力闪耀，让月光为我加冕"、嘉然干饭系、乃琳学霸系、心宜、思诺）
- 触发时机：开局、玩家出万能牌、AI 打出 +4、本局胜利/失败
- 显示在屏幕底部，主题色描边，3 秒淡出，不遮挡手牌

## 5. 其他优化
- 应援按钮更醒目：手牌剩 1 张时按钮脉冲动画 + 屏幕边缘提示
- 记牌器（可选开关，默认关）：显示各色已出张数，帮助老玩家
- 移动端：手牌横滑优化，按钮热区 ≥44px
