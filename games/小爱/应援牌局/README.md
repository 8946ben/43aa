# 一个魂 · 应援牌局

UNO 规则卡牌对战：你 vs 3 位成员 AI。四色即成员色（红=贝拉、粉=嘉然、蓝=乃琳、紫=思诺），万能牌是阿草。

**一句话玩法**：双击 `index.html` 浏览器打开 → 选模式点「开始牌局」→ 点手牌出牌（与当前颜色或数字/符号相同），没牌可出就摸 1 张，剩 1 张时 2 秒内按「应援！」免罚，先出完者胜。

零依赖、零构建，直接 `file://` 打开即可运行（含音效，无需任何音频文件）。

## 目录

```
index.html          页面骨架（浮层：开始 / 选色 / 结算 / 战绩；积分榜 / 记牌器 / toast 容器）
style.css           全部样式，含桌面三向座位 + 移动端横滑手牌 + 飞牌 / 命中 / toast 动画
js/constants.js     成员色、座位、贴纸表、计分常量、成员语录、设置键
js/deck.js          108 张牌构建与洗牌
js/rules.js         出牌合法性、手牌点数、颜色统计
js/ai.js            AI 贪婪策略（同色最多优先 / 功能牌留后 / 万能牌选自己最多的颜色）
js/audio.js         WebAudio 合成音效（零音频文件）+ 静音偏好
js/game.js          游戏状态机：发牌、轮转、功能牌、叠加罚牌、应援窗口、锦标赛积分、localStorage 战绩
js/ui.js            渲染、动画、语录 toast、设置面板、事件绑定
js/main.js          启动
assets/stickers/    头像 / 卡面点缀表情包（SVG / PNG 占位，可换成同名文件）
prompts/            各版本工单
```

## 规则要点

### 基础（v0.1）

- 出牌须与「当前颜色」或「数字 / 符号」匹配；万能牌随时可出，出后自由选色。
- 无牌可出摸 1 张，摸到能出可立即打出，否则点「过牌」。
- 跳过 / 反转 / +2 / 变色 / +4 全部生效；4 人局反转即反向，+2 与 +4 让下家摸牌并跳过其一回合。
- **应援**：手牌剩 1 张时出现「应援！」按钮，2 秒内点击免罚，超时罚摸 2 张。手牌剩 1 张时按钮脉冲、屏幕边缘亮起提示。
- AI 剩余 1 张自动应援，不罚牌。

### 赛制（v0.2）

开始面板可选：

| 模式 | 说明 |
| --- | --- |
| 快速单局 | 打完一局即结束，结算本局积分与排名 |
| 锦标赛 | 3 局两胜 / 5 局三胜，累计积分定冠军 |

- 每局胜者获得「其余三家手牌点数之和」作为本局积分，并计入累计积分与胜局数。
- 某位玩家先拿到 2 胜（5 局制为 3 胜）即提前结束，否则打满局数。
- 每局结束弹出局间结算：本局得分 + 累计积分 + 胜局数，按累计分排名，点「下一局」继续。
- 顶栏下方的积分榜实时按累计分排序展示 4 人（含你的高亮），座位上也显示积分与胜局。
- 总局结束显示完整排名表与冠军，可「再来一届」。

### 叠加模式（可选，默认关）

- 被 +2 / +4 时，若手里有可反打的牌，可把罚牌累计转嫁给下家：
  - **+2 只能压 +2**；**+4 可压 +2 或 +4**。
- 无人能接（或主动放弃）时，最后被指者一次摸走全部累计罚牌，并被跳过一回合。
- 界面中央显示「罚牌 xN」徽标；轮到你时会出现「认罚摸 N 张」按钮。

### 辅助（v0.2）

- **记牌器**（默认关，开局前可开）：顶栏显示各色已出张数（每种颜色共 25 张）。
- **音效**：出牌 click、摸牌纸摩擦、+2/+4 下滑低音、胜利上行琶音、失败下行、应援成功铃音；右上角 🔇 按钮或 `M` 键静音，偏好存 `localStorage`。
- **成员语录 toast**：开局、你打出万能牌、AI 打出 +4、本局胜负时，屏幕底部弹出成员语录，3 秒淡出，不遮挡手牌。
- 开局前的模式 / 赛制 / 开关会被记住，下次自动回填。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 出牌 | 点手牌 | 点手牌（手牌可左右横滑，带吸附） |
| 摸牌 | 点摸牌堆 / 空格 | 点摸牌堆 |
| 应援 | 点按钮 / U 键 | 点按钮 |
| 认罚（叠加模式） | 点「认罚」 | 同 |
| 静音 | 右上角按钮 / M 键 | 右上角按钮 |
| 重开 | 顶栏「重开」（重开整届） | 同 |

按钮热区在移动端 ≥ 44px。

## 素材替换

`assets/stickers/` 中是内置表情占位。
要换成真实 A-SOUL 表情包，把图片拷进该目录并修改 `js/constants.js` 里 `STICKERS[key].file` 的文件名即可；
图片加载失败时自动回退成 emoji + 成员色圆形占位，不会破版也不会报错。
