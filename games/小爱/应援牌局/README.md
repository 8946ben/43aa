# 一个魂 · 应援牌局

UNO 规则卡牌对战：你 vs 3 位成员 AI。四色即成员色（红=贝拉、粉=嘉然、蓝=乃琳、紫=思诺），万能牌是阿草。

**一句话玩法**：双击 `index.html` 浏览器打开 → 点「开始牌局」→ 点手牌出牌（与当前颜色或数字/符号相同），没牌可出就摸 1 张，剩 1 张时 2 秒内按「应援！」免罚，先出完者胜。

零依赖、零构建，直接 `file://` 打开即可运行。

## 目录

```
index.html          页面骨架（浮层：开始 / 选色 / 结算 / 战绩）
style.css           全部样式，含桌面三向座位 + 移动端横滑手牌
js/constants.js     成员色、座位、贴纸表、计分常量
js/deck.js          108 张牌构建与洗牌
js/rules.js         出牌合法性、手牌点数、颜色统计
js/ai.js            AI 贪婪策略（同色最多优先 / 功能牌留后 / 万能牌选自己最多的颜色）
js/game.js          游戏状态机：发牌、轮转、+2/+4/跳过/反转、应援窗口、胜负与 localStorage 战绩
js/ui.js            渲染与事件绑定
js/main.js          启动
assets/stickers/    头像 / 卡面点缀表情包（SVG 占位，可换成同名 PNG）
```

## 规则要点（Stage 1）

- 出牌须与「当前颜色」或「数字 / 符号」匹配；万能牌随时可出，出后自由选色。
- 无牌可出摸 1 张，摸到能出可立即打出，否则点「过牌」。
- 跳过 / 反转 / +2 / 变色 / +4 全部生效；4 人局反转即反向，+2 与 +4 让下家摸牌并跳过其一回合。
- **应援**：手牌剩 1 张时出现「应援！」按钮，2 秒内点击免罚，超时罚摸 2 张。
- 单局制：先出完者胜，积分为其余三家手牌点数之和；战绩存 `localStorage`（累计局数 / 胜场 / 最高积分 / 最近 5 局）。
- AI 剩余 1 张自动应援，不罚牌。

## 操作

| 操作 | 桌面 | 手机 |

| 出牌 | 点手牌 | 点手牌（可左右滑动） |

## 素材替换

`assets/stickers/` 中是内置 SVG 占位表情（`acao` `acao-gold` `diana` `bella` `eileen` `sinuo`）。
要换成真实 A-SOUL 表情包，把图片拷进该目录并修改 `js/constants.js` 里 `STICKERS[key].file` 的文件名即可；
图片加载失败时自动回退成 emoji + 成员色圆形占位，不会破版也不会报错。
