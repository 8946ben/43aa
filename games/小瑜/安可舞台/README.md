# 安可舞台 ENCORE STAGE

一句话玩法：太鼓式节奏游戏——音符沿横轨滚向太鼓，「咚」敲鼓面、「咔」敲鼓边，跟着三首原创合成曲目打完整场演唱会，热情槽攒满触发「ENCORE!!」安可狂热得分翻倍。

## 操作

- 鼓面「咚」：`F` 或 `J` · 鼓边「咔」：`D` 或 `K`
- 触屏：左半屏 = 鼓面，右半屏 = 鼓边（支持多指）
- 大音符（金环「双」）：同侧双键齐按 / 双指同按，得分 ×2
- `P` / `Esc` 暂停 · `M` 静音 · `R` 重开 · 选曲界面 `Enter` 开演
- 判定：PERFECT ±50ms / GREAT ±100ms / GOOD ±150ms，漏接 MISS 断连击并扣热情
- 热情槽满 100 进入 10 秒安可狂热（得分 ×2）；归零进入冷场（得分 ×0.5）
- 结算按准确率评 S/A/B/C/F，零 MISS 记 FULL COMBO；每曲每难度最高分存本机 localStorage

## 内容

- 3 首 WebAudio 实时合成原创曲目：夜航星 96BPM / 心动信号 128BPM / 无限安可 160BPM
- 谱面由旋律与鼓点事件确定性生成：EZ 正拍咚反拍咔、NM 完整主旋律鼓点流、HD 加踩镲与 crash 大音符
- 舞台调校：音符速度 1.0–3.0×、判定延迟 ±150ms、音量
- 演唱会舞台：五位 Q 版成员随拍起舞、聚光灯、LED 均衡器屏、观众荧光棒海

## 运行

纯静态，浏览器直接打开 `index.html` 即可（无需服务器）。

## 开发工具

`tools/cdp-shot.mjs`：CDP 驱动 headless Edge 的视觉/交互回归脚本（真实视口 + 虚拟时间 + 键鼠/触屏事件 + 控制台报错收集）。
调试参数：`?auto=1&song=0&diff=EZ&play=1` 自动开局/自动演奏，`&silent=1` 改用 performance 时钟（供虚拟时间确定性测试）。
