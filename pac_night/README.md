# 一个魂 · 购物之夜

一款致敬经典《吃豆人》（Pac-Man）的 A-SOUL 同人网页小游戏：深夜商场打烊前，带着成员冲进卖场收珠宝、躲小黑子、抢应援礼盒！

纯静态 HTML5 实现，零依赖、零构建、零联网。**双击 `index.html` 即可游玩**（file:// 直接可玩）。

---

## 灵感来源与原创点

- **玩法基底**：经典《吃豆人》——俯视迷宫、格心转向、能量豆反杀、四鬼围剿、隧道传送。
- **主题改造**：「购物之夜」——珠宝豆是货架上的小首饰，能量豆是「甜蜜陷阱」药丸，追兵是粉丝小黑子 ×3 与吉祥物阿草。
- **原创机制**：中央**打烊礼盒**——每关吃满 40 / 70 / 100 颗后，迷宫中央限时刷出「一个魂应援礼盒」（8 秒消失，500 分）。
- **五人可选**：默认三人组（贝拉 / 嘉然 / 乃琳）+ 两名达成累计分数解锁的扩展成员（心宜 / 思诺），每人一个真实生效的被动技能。
- 迷宫内角色与鬼全部由 Canvas 矢量绘制（Q 版少女造型 + 灰绿连帽衫小黑子 + 白色雪貂阿草）；表情包素材只用于菜单 / 过场 / 结算。

## 玩法

- 方向键 / WASD 移动，吃光全场**珠宝豆**（10 分）过关；四角**大颗奶油宝石**（50 分）触发「甜蜜陷阱」：鬼变蓝可反吃，连吃 200 / 400 / 800 / 1600 分。
- 被抓扣 1 命，共 3 命；死亡后短暂无敌并重置位置。
- 两侧隧道左右传送；逐关鬼更快、甜蜜陷阱更短（7s → 5s → 3s）。
- 通关 3 张地图后播放「午夜收货 · 满载而归」结局；3 命耗尽则结算失败。

## 技术说明

- 纯静态：无 ES module、无 fetch、无 Worker、无 CDN；经典 `<script>` 顺序引入。
- Canvas 渲染：21 列 × 23 行迷宫，26px 瓦片；墙体霓虹描边预渲染到离屏画布。
- 手感：`requestAnimationFrame` + 固定逻辑步长（1/120s）；移动为「格间插值」，转向 / 吃豆 / 鬼决策只发生在格心，输入带预输入缓冲，支持随时反向。
- 音效：WebAudio 实时合成（waka 吃豆、能量豆、吃鬼、死亡、过关 jingle、礼盒、护身、背景警笛），无外部音频文件。
