# 守护五周年 · 应援防线

A-SOUL 同人塔防小游戏（纯静态 HTML5，零依赖、零构建、零联网）。
双击 `index.html`（file:// 协议）即可游玩。

> **灵感来源**：玩法借鉴《保卫萝卜》与经典塔防（固定蜿蜒路径、环形菜单建塔、
> 波间倒计时提前召唤等），并做 A-SOUL 应援化改造——五名成员化身五种应援塔，
> 守卫五周年舞台不被「虚无」与「小黑子」吹灭灯光。
> **关于登场成员**：默认三人组（贝拉 / 嘉然 / 乃琳）领衔，但塔防玩法的
> 五种塔位设计天然需要全阵容——心宜与思诺作为二期应援力量加入防线，五人全员登场。

---

## 玩法

- 敌人从左侧「虚无漩涡」出生，沿蜿蜒路径进攻右侧**五周年舞台**（耐久 10 点）。
- 点击发光空地格 → 弹出**环形菜单**选塔；点击已建塔可查看射程圈、**升级**（3 级）或**卖出**（返还 70% 投入）。
- 击杀敌人掉落**应援值**（金币），清波有额外奖励；波间点「下一波」**提前召唤**，按剩余秒数每秒奖励 2 应援值。
- 共 **15 波**，撑过即胜利，按剩余耐久评 1~3 星；耐久归零则失败。
- 支持 **1x / 2x 倍速**、**P / Esc 暂停**、**M 静音**（音效为 WebAudio 实时合成）。
- 最高纪录（最高星 / 最远波次）存于 `localStorage`，键名 `guardtour_best_v1`。

## 素材来源与声明

- 素材取自本地 A-SOUL 二创素材库 `asoul-materials/assets/`（只读拷贝），
  已重命名为 ASCII 文件名存放于 `assets/`：
  - 塔头像：贝拉 / 嘉然 / 乃琳表情包；心宜、思诺无表情包，使用官方公式图（白底 JPG，绘制时垫应援色圆形裁剪）。
  - 吉祥物阿草表情包、A-SOUL 团体 logo、结算用表情包均同库拷贝。
- 敌人、弹道、特效全部为 canvas 矢量绘制；音效为 WebAudio 振荡器实时合成，无任何外部资源。
- 本作为 **A-SOUL 同人非商用作品**，与官方无关；请勿用于商业用途。
