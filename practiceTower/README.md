# 加练魔塔

A-SOUL 同人小游戏 · 纯静态 HTML5 爬塔解谜 RPG（零依赖 / 零构建 / 零联网）

**灵感来源**：玩法机制致敬 4399 经典 Flash 游戏《魔塔》（确定性数值战斗、钥匙开门、
宝石成长、层数推进），并做了 A-SOUL「加练」主题改造：默认三人组——贝拉 / 嘉然 / 乃琳
均可作为主角，爬上 21 层练习大楼，扫清「拖延症魔物」，在天台舞台点亮聚光灯。
心宜 / 思诺在 7F / 14F 担任守关 NPC，吉祥物阿草在关键楼层乱入提示；
怪物则是拖延症史莱姆、杠精、小黑子、数据女工等二创形象。

> 每人加练一天！！！ —— 努力闪耀的人，让月光为她加冕。

## 怎么玩

双击 `index.html` 即可（Chrome / Edge 等现代浏览器，file:// 直接可玩）。

- 标题界面**选择主角**（默认三人组，见下表），开场剧情按所选主角切换口吻。
- 走向怪物会弹出**战斗预览**（预计回合 / 损血），确认后进入确定性战斗：
  每回合伤害 = 自己舞力 − 对方护体（反向同理），玩家先手，直到一方倒下。
- 撞门消耗对应颜色的**门禁卡钥匙**；宝石（舞蹈秘籍 / 护膝 / 应援棒）直接提升属性。
- 3F **Queen 商店**用应援金购买属性（价格逐次上涨；选乃琳主角享 8 折）。
- 7F 心宜、14F 思诺是守关小 BOSS，10F 有中 BOSS「镜子里的自己」，
  21F 决战**惰怠魔壬**——击败守关者会加入应援，获得全属性加成。
- 打不过、走死了也没关系：体力归零自动回档到**本层入口**重试；
  「炸弹 ×2」可直接跳过一场战斗；击败守关者后可在**楼层跳跃**中往返已到达楼层。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 一次移动一格（撞门用钥匙、撞怪弹战斗确认、撞 NPC 触发剧情） |
| 空格 / 回车 / 点击 | 推进对话 |
| 1 | 魔物图鉴（数值 + 一行吐槽） |
| 2 | 楼层跳跃（已到达的楼层随时往返，进度保留） |
| 3 / Esc | 暂停菜单（含清档重开、回标题） |
| M | 静音切换（音效 + BGM 全部合成自 WebAudio，无外部音频文件） |

## 存档说明

- 存档键 `ptower_save_v2`，结构含 `member` 字段（所选主角）。
- **不迁移旧档**：v1（`ptower_save_v1`，旧版单人存档）会被直接忽略，需重新开始。
- 自动存档时机：进入新层 / 战斗结束 / 拾取 / 商店购买 / 事件结束；
  标题页可「继续爬塔」与「楼层跳跃」。

## 21 层流程提示（轻微剧透，可跳过）

| 层 | 提示 |
| --- | --- |
| 1F–2F | 热身层，先拿舞蹈秘籍，习惯「看预览再开战」 |
| 3F | Queen 商店开张；攒应援金，优先舞力 |
| 4F–6F | 第一次蓝门；小黑子开始出现，注意护体别落太远 |
| 7F | 红门守关：二期舞担**心宜**。战前建议舞力 ≥ 24、护体 ≥ 22，备好血量 |
| 8F–9F | 换挡层：懒筋怪 / 爬行怪 / 焦虑水母，多囤能量饮料 |
| 10F | 中 BOSS「镜子里的自己」——躺平幻象，别被她动摇；觉得紧可回去补属性或用炸弹 |
| 11F–13F | 虚无残影登场，口诀是「先加舞力再加护体」 |
| 14F | 红门守关：**思诺**的声压很痛，务必厚血 + 高护体 |
| 15F–17F | 惰怠幼虫出现；这里开始每层都很凶，商店常回家 |
| 18F–20F | 冲刺段，20F 阿草会给你最后的叮嘱 |
| 21F | 终战**惰怠魔壬**。全应援到位后，点亮聚光灯——月光加冕结局（附所选主角专属点评） |

## 数值说明（自查）

- 初始属性随主角（见上表）；伤害公式 `max(1, 攻-防)`，玩家先手。
- 三主角分别以「全清、不逛商店」的保守模型经脚本推演，全程无必死点：
  贝拉最低 boss 余量 79%（7F，被动无损胜 66 场滚雪球）、
  嘉然 46%（10F，靠 1400 血与回复 ×1.5 硬扛）、乃琳 63%（10F，威慑加速 boss 战）。
- 商店价格 15 起步、每次 +10（乃琳享 8 折），终局剩余应援金可再买约 20 次，
  是防「走死」的救济阀。
- 每层地图经过连通性 + 钥匙闭环脚本验证：钥匙与门数量持平、无死锁层。
