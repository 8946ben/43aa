# 闪耀双人舞台 · 冰火协奏

A-SOUL 同人 · 纯静态 HTML5 双人同屏协作平台解谜游戏。
双击 `index.html`(file:// 协议)即可游玩,零依赖、零构建、零联网。

## 灵感来源

玩法骨架致敬 4399 经典双人协作游戏**《森林冰火人》(冰娃火娃)**——红蓝双角色、
液体免疫分路、双人各站同色出口门过关。在此基础上做了两块原创改造:

1. **搭档选择制**:角色不再固定为心宜 & 思诺两人,而是从「红莲组(火)」与
   「沧海组(水)」各选 1 人自由组队,共 6 种组合,默认推荐「贝拉 & 乃琳」;
2. **舞台化机关**:把经典机关包装成演唱会舞台元素——压力踏板、拉杆、红蓝桥
   (可作升降/换桥路线)、可推动的音箱、聚光灯(冻结水池成冰桥)、上升气流风扇、
   单向平台。

## 玩法

- 一块键盘,双人同屏协作:碰到本组免疫色以外的致命液体即演出事故,本关重开
  (收集品一并重置)。
- 收集品:**红音符**(红莲侧限定)、**蓝星光**(沧海侧限定)。
  全收集 = 3 星;累计 **18 星**解锁隐藏第 9 关「安可舞台」。
  进度保存在 localStorage 键 `firewater_progress_v2`(含上次的搭档选择)。
- 每关两位成员**各自站上自己应援色的出口门**即过关,缺一不可。
- 第 1 关由吉祥物**阿草**(雪貂)举牌分步教学;阿草表情包也会在失败画面登场。
- 通关第 8 关或隐藏关后进入结局画面:两位成员走向中央**击掌**,「闪耀舞台,
  正式开演!」。

## 双人操作表(同屏双人,一块键盘)

| 红莲侧(火) | 沧海侧(水) | 动作 |
| --- | --- | --- |
| A / D | ← / → | 左右移动 |
| W | ↑ | 跳跃(长按跳更高;液体里按住可上浮) |
| S | ↓ | 从单向平台主动落下 |
| 靠近机关轻触 | 靠近机关轻触 | 扳动拉杆 |
| P / Esc | 全局 | 暂停 / 继续 |
| R | 全局 | 重开本关 |
| M | 全局 | 静音(WebAudio 合成音效开关) |

## 组别与液体规则

- **红色火光池**:红莲组免疫(可在其中游泳),沧海组碰即败;
- **蓝色水池**:沧海组免疫(可在其中游泳),红莲组碰即败;
- **绿色虚无液**:两组都碰不得;
- **注意**:嘉然是粉色系,但「暖色 = 火」,属于**红莲组**。

## 机关图鉴(舞台化原创)

| 机关 | 说明 |
| --- | --- |
| 压力踏板 | 金色=踩住才生效(hold),青色=踩过一次永久生效(once) |
| 拉杆 | 轻触在 0/1 间切换,驱动红蓝桥或聚光灯 |
| 红蓝桥 | 拉杆切换,同组桥梁实/虚互换;可当换桥/升降路线用 |
| 音箱 | 可推动的箱子:垫脚上高台,或推去压住踏板 |
| 聚光灯 | 点亮时把光区内的蓝色水池冻结成冰桥;熄灭即解冻 |
| 风扇 | 常开上升气流,站进气流区被托举升空 |
| 单向平台 | 可从下方跳穿、上方站立;按「下」主动落下 |

## 6 种搭档组合

从红莲组选 1 人 + 沧海组选 1 人,共 3 × 2 = 6 种组合(菜单默认高亮推荐 **贝拉 & 乃琳**):

| 红莲组(火,WASD) | × | 沧海组(水,方向键) |
| --- | --- | --- |
| 贝拉 #DB7D74(队长舞担,梗:每人加练一天 / 拖拉机下山) | × | 乃琳 #576690(御姐 Queen,梗:荷尔蒙甜蜜陷阱 / 奶淇琳) |
| 嘉然 #E799B0(吃货,梗:顿顿解馋 / 嘉心糖;暖色即火) | × | 思诺 #7252C0(二期声乐,梗:枝江邓紫棋 / 让海听见我的声音) |
| 心宜 #C93773(二期元气,梗:动捕杀手 / 所有目光看向我) | × | |

**组合差异只在表现层**:Q 版小人的发色/发型剪影(贝拉高马尾、嘉然双丸子、
心宜双马尾、乃琳长卷发、思诺长直发)、应援色裙装、名字、台词、出口门颜色、
界面点缀色随成员变化;**关卡布局与解谜逻辑对所有人完全一致**。

## 技术说明

- 纯静态:经典 `<script>` 顺序引入 `js/data.js` → `js/game.js`,无 ES module、
  无 fetch、无 Worker、无 CDN;
- canvas 960×640(30×20 格,每格 32px),`requestAnimationFrame` + dt,目标 60fps;
- 平台物理:分轴碰撞、土狼时间(coyote time)、跳跃输入缓冲、可变跳跃高度、
  单向平台单向落穿;
- 动态实体(桥/门/冰)带防夹处理:门落/桥现时对重叠玩家豁免,冻结水池时会把
  泡在水中的沧海侧玩家托出冰面。
